# Рабочее пространство Арбуза

Ассистент ведёт записи здесь. Принципы: коротко, по делу, мелкие файлы.

- `ABOUT.md` — кто ты, предпочтения, договорённости.
- `inbox.md` — быстрые заметки/идеи/вопросы, ещё не разложенные.
- `log/YYYY-MM.md` — журнал: 1–3 строки на встречу, что решили.
- `areas/` — темы: `study` `work` `code` `hobby` `mind`.
- `projects/` — код и материалы проектов (крупное выносим отдельно).
- `scratch/` — черновики и мусор, в git не попадает.

Правила git: только ветка `arena/01a09069-workspace`, merge никогда,
никаких бинарников/датасетов, файлы не переписываем целиком без нужды.
