# Blade — прототип боёвки

`npm i && npm run dev` → http://localhost:5173

## Что есть
- Процедурные модели (без внешних ассетов): гуманоид с суставами (`src/models/humanoid.ts`), меч, параметризованный характеристиками оружия (`src/models/sword.ts`), арена-руины.
- Боевая система (`src/combat/`): 4 направления клинка (L/R/сверху/укол), лёгкий/силовой удар, блок, парирование (окно 160 мс), уворот с i-frames, стамина, столкновение клинков.
- Столкновение: если оба в атаке и направления встречные — исход по силе: тип удара × вес × качество × стамина, ±15% зона «оба отскочили».
- ИИ противника: держит дистанцию, реагирует на замах (блок/уворот/встречный), бьёт в открытую сторону.
- Процедурная анимация по фазам, HUD, лог событий.

## Управление
WASD, мышь — камера; резкое движение мыши задаёт направление клинка (индикатор в центре). ЛКМ тап — лёгкий, зажать — силовой. ПКМ — блок, в первые 160 мс — парирование. Space — уворот. R — рестарт.
